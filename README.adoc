= arch-install

Automated installer for a personal vanilla Arch Linux environment.
Tailored to one author's workflow; use the https://wiki.archlinux.org/title/Installation_guide[Arch Wiki] as the authoritative reference.

== Quick start

Prepare an https://archlinux.org/download/[Arch Linux live USB] and boot from it.

=== 1. Set your keyboard layout (German)

    loadkeys de-latin1

=== 2. Connect to Wi-Fi (if needed)

    iwctl

    station device list
    station device connect "NetworkName"

=== 3. Clone and run the installer

    git clone https://github.com/ityreh/arch-install.git
    cd arch-install
    bash bin/arch-install.sh

The full repository is required: the entry point sources `bin/lib/common.sh`,
reads `config/settings.sh` and copies the repository into the target in phase 2.

To pass options (forwarded to phase 1):

    bash bin/arch-install.sh --disk /dev/nvme0n1 --swap 8G

== Structure

    .
    ├── config/
    │   └── settings.sh      # Single source of truth (hostname, locale, git identity...)
    ├── packages/
    │   └── apps.csv         # Package catalog: category,source(R/A),package,description
    ├── bin/
    │   ├── arch-install.sh  # Entry point: runs phases 10 → 20 → 30 → 40 → 50
    │   ├── 10-partition.sh  # Phase 1: wipe, partition, format, mount
    │   ├── 20-bootstrap.sh  # Phase 2: pacstrap, fstab, copy repo into target
    │   ├── 30-chroot.sh     # Phase 3: bootloader, locale, users (inside chroot)
    │   ├── 40-packages.sh   # Phase 4: dialog package selection + pacman install
    │   ├── 50-user.sh       # Phase 5: AUR helper, git identity, dotfiles, user tools
    │   └── lib/
    │       └── common.sh    # Shared helpers, dialog wrappers, state management
    ├── Makefile
    └── AGENTS.md

=== Pipeline

1. **10-partition** (live USB, root) — interactive prompts for disk, wipe method, swap; writes runtime state to `/var/lib/arch-install/state.env`
2. **20-bootstrap** (live USB, root) — pacstrap base packages, generate fstab, copy this repo to `/opt/arch-install` on the target
3. **30-chroot** (inside `arch-chroot /mnt`) — bootloader, locale, hostname, root + user passwords; chains to 40 and 50
4. **40-packages** (root) — checklist of app groups from `packages/apps.csv`; pacman installs, AUR failures queued
5. **50-user** (as target user) — AUR helper bootstrap, AUR queue install, git identity, dotfiles clone + stow, cargo tools (workmux, starship), ble.sh

After the first reboot, re-run phases 40/50 standalone if needed:

    sudo /opt/arch-install/bin/40-packages.sh      # as root
    bash /opt/arch-install/bin/50-user.sh            # as user

== Development

Lint all scripts (requires https://github.com/koalaman/shellcheck[shellcheck]):

    make check

Run the smoke tests against a podman archlinux pod (no real hardware needed):

    make test            # quick checks
    make test-full       # also installs a few packages (requires root)

List the package catalog:

    make list
